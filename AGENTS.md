# AGENTS.md

Единый источник инструкций для любого агента (Claude Code, Codex, Cursor и др.). Формат по NOTATION v1: четыре раздела.

## Project
deckhouse_helm_generator (тип: development).

## Commands
```bash
# сборка:   <команда>
# тесты:    <команда>
# линт:     <команда>
```

## Structure
- `ARCHITECTURE.md` — контекст, компоненты, решения (таблица ADR), журнал изменений
- `decisions/` — файлы значимых решений `ADR-NNN-slug.md` (правила в `decisions/README.md`)
- `BACKLOG.md` — очередь работ
- `.notation/doc.toml` — профили проверки документов проекта

## Rules
- Перед правкой читай файл; не придумывай API — проверяй по коду.
- Значимое решение: строка в таблице ADR (`ARCHITECTURE.md`, раздел 3) и строка в журнале изменений (раздел 6); крупное решение: файл в `decisions/`.
- Тесты зелёные до коммита; секреты не коммитить.
- Перед коммитом документы проверяет `notation-lint gate --staged` (его вызывает pre-commit); новое E блокирует коммит.
- Явный объём: делай только запрошенное, побочные находки — отдельным списком.
